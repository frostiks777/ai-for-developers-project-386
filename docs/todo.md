1. **Схема БД**: нет `hosts` / `availability_rules`, email, статусов, диапазонов времени.
2. **API**: нет версионирования `/api/v1`, хостов, фильтра по дате; тело брони другое.
3. **Форма**: спека требует email (обяз.) + телефон/telegram (опц.) + комментарий — сейчас только имя + телефон.
4. **Экраны**: нет `/book/:hostId`, экрана успеха и `/dashboard`.
5. **Логика слотов**: нет алгоритма генерации (§4.1 спеки) — только статический сид.
6. **Гонки**: check-then-insert без транзакции (спека требует exclusion constraint).
