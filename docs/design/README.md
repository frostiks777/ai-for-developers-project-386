# Дизайн: утверждённый вариант A + D

Пакет для внедрения нового дизайна «Календаря звонков»: десктоп — вариант **A** (три колонки), телефон — вариант **D** (лента дат и нижняя панель), обе раскладки в **светлой и тёмной темах**.

| Файл | Что внутри |
|---|---|
| [`design-spec.md`](design-spec.md) | Спецификация: токены, шрифты, раскладки, компоненты, состояния, a11y, тексты |
| [`implementation-plan.md`](implementation-plan.md) | Пошаговый план для агента: этапы, файлы, тесты, критерии приёмки |
| [`test-contract.md`](test-contract.md) | Что нельзя ломать в существующих тестах и что в них можно поменять |
| [`tokens.css`](tokens.css) | Готовые CSS-переменные shadcn для `:root` и `.dark` |
| [`tailwind.config.snippet.js`](tailwind.config.snippet.js) | Дополнения к `tailwind.config.js` |
| `mockups/*.html` | Статичные эталонные макеты (открыть в браузере) |
| `screenshots/*.png` | Скриншоты макетов: десктоп 1280 px, телефон 390 px |

Данные в макетах условные (24 сентября 2026, пояс Europe/Moscow, слоты 13:00–20:20). На экранах форм нарочно показана ошибка в email: так выглядит состояние ошибки.
