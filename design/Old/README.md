# Пакет дизайна для ИИ-агента

Утверждённый дизайн «Календаря звонков»: **A на десктопе + D на телефоне, светлая и тёмная темы**.

Папка `repo/` повторяет структуру репозитория: скопируйте её **содержимое** в корень `ai-for-developers-project-386`, и файлы встанут на свои места. Ни один существующий файл не перезаписывается.

```
repo/.agents/skills/apply-design/SKILL.md      скилл для агента
repo/docs/adr/0006-visual-redesign-and-themes.md   черновик ADR
repo/docs/design/
  README.md                  оглавление, список экранов, таблица контраста
  design-spec.md             спецификация дизайна
  implementation-plan.md     пошаговый план (этапы 0–7) и приёмка
  test-contract.md           что нельзя ломать в тестах
  tokens.css                 CSS-переменные shadcn для светлой и тёмной тем
  tailwind.config.snippet.js дополнения к tailwind.config.js
  mockups/*.html             16 эталонных макетов
  screenshots/*.png          16 скриншотов макетов
PROMPT.md                    готовый промпт для агента
README.md                    этот файл
```

## Как использовать

1. Скопируйте содержимое `repo/` в корень репозитория: `cp -r design-package/repo/. ai-for-developers-project-386/`.
2. Закоммитьте `docs/design/`, `docs/adr/0006-…` и скилл: `docs: add approved design package`.
3. Запустите агента и вставьте текст из `PROMPT.md`.
4. После работы агента впишите реальные данные организатора в `src/config/host.ts` (имя, инициалы, название встречи, формат).

## Что решено в дизайне

- Цвета общие для обеих раскладок: светлая тема — тёплый светлый фон и бирюзовый акцент `#0F766E`, тёмная — почти чёрные поверхности из варианта D и мятный акцент `#5FD4C0`. Чтобы вернуть в тёмную тему лаймовый акцент из исходного варианта D, достаточно поменять `--primary`, `--ring`, `--accent*` в блоке `.dark` файла `tokens.css`.
- Шрифты: Golos Text (интерфейс) и Lora (крупные заголовки), оба с кириллицей.
- При выборе даты сразу выбирается первый свободный слот, поэтому кнопка «Забронировать» видна сразу. Это ещё и сохраняет совместимость с текущими тестами.
- Кнопки «Google Календарь» и «.ics» — необязательный этап 5b, считаются на фронтенде.
