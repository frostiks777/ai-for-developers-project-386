# Промпт для ИИ-агента

Скопируйте текст ниже в агента (opencode, Claude Code, Cursor и т. п.), запущенного в корне репозитория `ai-for-developers-project-386`, **после** того как содержимое папки `repo/` из пакета скопировано в корень репозитория (см. `README.md` пакета).

---

Задача: внедрить утверждённый редизайн фронтенда «Календаря звонков» — десктопная раскладка A, мобильная раскладка D, светлая и тёмная темы.

Источник истины — `docs/design/`:
- `design-spec.md` — что и как должно выглядеть и работать;
- `implementation-plan.md` — порядок работ (этапы 0–7), файлы, тесты, критерии приёмки;
- `test-contract.md` — какие селекторы тестов нельзя ломать и какие правки тестов разрешены;
- `tokens.css`, `tailwind.config.snippet.js` — готовые токены;
- `screenshots/*.png` и `mockups/*.html` — визуальный эталон (десктоп 1280 px, телефон 390 px, обе темы).

Используй скилл `.agents/skills/apply-design/SKILL.md`, а также `verify` и `commit-push`.

Порядок:
1. Прочитай `AGENTS.md`, `docs/conventions.md`, затем все файлы `docs/design/` и посмотри скриншоты.
2. Создай ветку `feat/redesign-a-d-themes`.
3. Выполняй этапы 1–7 из `implementation-plan.md` строго по порядку. После каждого этапа — `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`; если что-то красное — чини, пока не станет зелёным, затем коммит в формате Conventional Commits.
4. После этапов 2, 3, 4 и 6 запусти приложение (`npm run server:dev` и `npm run dev`) и сравни экраны со скриншотами в обеих темах на ширине 1280 и 390 px. Расхождения исправь или запиши в раздел «Отклонения» в `docs/design/README.md`.
5. В конце выведи: список коммитов, результаты проверок, список отклонений от макетов (если есть) и что осталось сделать вручную (данные организатора в `src/config/host.ts`).

Ограничения:
- Бэкенд (`server/`), API и zod-схемы не менять.
- `.github/workflows/hexlet-check.yml` и имя репозитория не трогать.
- Не удалять и не ослаблять существующие проверки в тестах; разрешённые правки тестов — только из `test-contract.md`.
- Цвета — только через токены, без inline-стилей, без `any`.
- Этап 5b (экспорт в Google Календарь / .ics) — делать, только если всё остальное готово и зелёное.
